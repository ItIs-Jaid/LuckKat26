# AGENTS.md — DevSecLoc KB working conventions

This repo is a local-first knowledge base (SQLite `kb/kb.db`) plus a review-only
markdown/CSV export under `kb/export/`. The agent and the operator consult it for coding
questions across Python · C/C++ · Web (JS/TS) · DevOps/Docker · Security.

## Source of truth
- `kb/kb.db` (SQLite) — the live store. NEVER treat exports as authoritative.
- `kb/export/` — humanized `.md` + `.csv` generated by `kb/kb_export.py`. Review-only mirror.

## Scripts (deterministic unless noted)
- `python kb/init.py`            — create the DB from `kb/schema.sql`
- `python kb/kb_export.py`       — regenerate review mirror
- `python kb/kb_capture.py ...`  — log code_reviews / errors (see --help)
- `python kb/kb_daily_update.py` — deterministic vuln feed poll + URL revalidation

## Code-review / error capture (do this whenever we write or debug code here)
- After fixing a bug or finishing a review: `kb/kb_capture.py review ...`
- On a recurring error: `kb/kb_capture.py error ...` (auto bumps recurrence)
- Verification: a finding is only `verified_by` once the operator confirms or an approved model
  signs it: `kb/kb_capture.py verify review <id> --by <operator>` (or `model:<name>`).
- Verified findings feed `patterns`/`libraries` so the KB self-improves.

## Daily updater + model gate
- Run by a Hermes cronjob on a FIXED daily schedule (deterministic recurring event).
- Deterministic path needs no LLM: polls NVD / GitHub Advisory (OSV) / revalidates URLs.
- LLM synthesis is GATED: the updater stages new items and EXITS 42; the agent must
  ASK THE OPERATOR to pick the model, then run `--synth --model <name>`. No model pick -> the
  deterministic findings stand and are queued in `review_queue` for later review.

## Local-first boundary
- No cloud writes. Commits are local. GitHub remote + push only after the operator approves.
- `561.md` governs this project; honor its local-first posture.

## Seed data
- Initial KB seeded by 5 supervisor agents (Python/CPP/Web/DevOps/Security) each fanning
  to leaf agents. Merged via `kb/seed_merge.py` (or inline) into SQLite, then export.
